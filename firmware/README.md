
# ESP32 Firmware

This directory contains the firmware developed for the
Digital Twin-Based Temperature Monitoring, Prediction
and Control of a Thermal Process.

## Firmware Components

- Real-time temperature acquisition using DS18B20
- ESP32-based sensor data processing
- Thermal process temperature prediction
- MQTT-based data communication
- Temperature threshold monitoring

## Hardware

- ESP32 DevKit
- DS18B20 temperature sensor
- Electric kettle thermal prototype

## Sensor Connection

| Component | ESP32 Pin |
|---|---|
| DS18B20 Data | GPIO 4 |
