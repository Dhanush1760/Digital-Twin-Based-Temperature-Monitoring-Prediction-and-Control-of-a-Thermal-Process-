
# Software Components

This directory contains the software components
developed for the thermal process Digital Twin.

## Prediction Model

The temperature prediction component uses
Linear Regression to forecast future temperature.

## MQTT Communication

MQTT is used for temperature data communication
between the physical process and virtual system.

## Software Components

- Temperature prediction
- Prediction error evaluation
- MQTT communication
- Temperature data processing

The actual source files will be added after
the software components are finalized.
