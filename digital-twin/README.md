
# Digital Twin Development

This directory contains the virtual representation
of the thermal process.

## Digital Twin Components

### SolidWorks

The 3D kettle model is developed using SolidWorks.

### Unity

Unity is used to develop the virtual thermal process
representation.

## Functionalities

- 3D kettle visualization
- Virtual process representation
- Temperature data visualization
- MQTT-based communication
- Temperature-dependent virtual representation

The complete Unity and SolidWorks project files
will be added to their respective directories.
